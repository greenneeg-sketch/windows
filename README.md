# 숨글 — 창에 남기는 따뜻한 한 줄

![숨글](logo.png)

그날 마음에 맞는 유리창 앞에 서서 포스트잇을 붙이고 가는 1인칭 3D 웹 공간입니다.

- 1인칭 시점으로 걸어서 창문 앞까지 가요 (조이스틱 / WASD, Space 점프, C 앉기)
- 테마 창 4곳: 수고했어 창(노을 호숫가), 털어놓는 창(밤바다), 다짐하는 창(새벽 안개 숲), 소원 창(유채꽃 들판)
- 포스트잇에는 붙인 사람의 시·도만 "서울에서"처럼 작게 남아요. 위치는 붙일 때만 묻고, 시·도는 휴대폰에서 계산해 좌표는 서버로 보내지 않아요. 끌 수도 있어요.
- 포스트잇에 손글씨나 그림을 그리고, 글자를 원하는 자리에 놓고 돌릴 수 있어요 (글씨체 6종)
- 내가 붙인 포스트잇은 수정하거나 떼어낼 수 있어요
- 다시 들어오면 내 포스트잇에 새로 달린 공감을 첫 화면에서 알려줘요
- 창마다 링크가 있어요: `#sugo`(수고했어) `#talk`(털어놓는) `#vow`(다짐하는) `#wish`(소원) — 링크로 들어오면 바로 그 창 앞에 서요
- 포스트잇을 인스타 스토리 크기(1080×1920) 이미지로 만들어 공유·저장할 수 있어요
- 사진 모드: 직접 구도를 잡아 9:16 · 1:1 · 전체 화면으로 찍고, 작은 로고를 넣어 공유할 수 있어요
  - 줌 1~4배(두 손가락·막대·휠), 카메라 높이 0.4~3.6m(높이 붙은 포스트잇도 정면으로)
  - 아웃포커스: 누른 곳에 초점을 맞추고 앞뒤를 흐리게, 흐림 정도 조절
- 욕설·링크·전화번호 필터, 신고 버튼, 하루 3장 제한

## 실행

정적 파일만으로 동작합니다. GitHub Pages에서 `main` 브랜치의 루트(`/`)를 배포하면 됩니다.
로컬에서는 `python3 -m http.server` 후 `http://localhost:8000` 으로 열어주세요.

## 연말 시즌

- **새해 소원 창** (`#newyear`): 11월 15일 ~ 1월 31일에만 열리는 다섯 번째 창. 눈 내리는 밤, 창틀과 소나무에 반짝이는 전구, 멀리서 울리는 종소리
- 12월·1월에는 모든 창에 눈이 살짝 내려요
- 12월 31일 23:59:50부터 화면 가운데 카운트다운, 1월 1일 0시부터 10분간 불꽃놀이와 새해 인사 (기기 시간 기준)
- 새해 소원 창 공유 카드: 눈송이 배경과 금색 창 이름

## 몰입 요소

- 창마다 다른 소리(파일 없이 코드로 생성): 수고했어 — 물결·물방울·먼 새소리 / 털어놓는 — 파도·풀벌레 / 다짐하는 — 숲 바람·아침 새 / 소원 — 들판 바람·풀잎·종달새
- 창 앞에 서면 포스트잇이 살짝 커져 읽기 쉬워져요
- 작은 동물들: 수고했어 — 새 떼·잠자리·나비·다람쥐 / 털어놓는 — 모래사장의 게 / 다짐하는 — 새·다람쥐·토끼 / 소원 — 토끼·나비·종달새
- 포스트잇 수명: 30일 + 공감 1개당 2일(최대 180일). 끝이 다가오면 바래고 기울어지다 떨어져요. 읽기 화면에 남은 날짜가 보여요

## 관리자 페이지

`admin.html` — 관리자 키로 들어가서 신고된 포스트잇을 보고 숨기기·되살리기·삭제를 할 수 있어요. 검색엔진에 노출되지 않게 막아뒀고, 키는 서버에 해시로만 저장돼요.

## 서버 (Supabase)

포스트잇은 Supabase(`yurichang` 프로젝트, 서울 리전)에 저장되어 모두에게 보입니다. 30초마다 새 포스트잇을 불러옵니다.

- 누구나 숨겨지지 않은 포스트잇만 읽을 수 있고, 기기 ID와 수정 키는 읽을 수 없습니다.
- 쓰기·수정·삭제·공감·신고는 모두 서버 함수(`post_note`, `edit_note`, `delete_note`, `heart_note`, `report_note`)를 통해서만 됩니다.
- 서버에서 다시 검사: 욕설·링크·전화번호 필터, 기기당 하루 3장, 내용 크기 제한, 서버 전체 분당 60장 제한
- 수정·삭제는 글을 붙인 기기에 저장된 비밀 키가 있어야만 됩니다.
- 서로 다른 기기 3곳에서 신고하면 모두에게서 내려갑니다. 공감은 기기당 1번입니다.
- 서버에 연결이 안 되면 그 기기에만 저장합니다.

스키마는 `supabase/schema.sql` 에 있습니다. 창 ID는 내부적으로 `mapo`(수고했어), `busan`(털어놓는), `gangneung`(다짐하는), `jeju`(소원)를 그대로 씁니다.

### 알려진 한계

- 손글씨·그림은 글자 필터로 걸러지지 않으므로 신고로 관리합니다.
- 하루 제한: 기기당 3장 + 같은 네트워크(IP)당 10장. IP는 그날만 쓰는 해시로만 저장해 원래 주소는 남지 않습니다.

## 살아있는 창 (v23)
- 실제 시간(서울) 반영: 새벽 5–7시 · 낮 · 노을 17시– · 밤 19:30–. 밤엔 별·반딧불·창틀 전구·가로등, 귀뚜라미 소리.
- 서울 실시간 날씨(Open-Meteo, 15분마다): 비 → 빗줄기 + 유리창 빗방울 + 빗소리, 눈 → 눈.
- 털어놓는 창(밤바다)·새해 소원 창은 항상 밤 풍경 유지.
- PWA: manifest.json + sw.js (풍경·모델 파일 캐시, HTML은 네트워크 우선). 아이폰: 공유 → 홈 화면에 추가.
